토큰 비용은 이렇게 계산해요

AI API는 글자 수가 아니라 토큰 단위로 요금을 받아요. 가격표는 보통 100만 토큰(1M)당 달러로 적혀 있어서, 내 사용량을 100만으로 나눠 곱하면 월 비용이 나와요.

월 입력 토큰 = 요청 수 × 요청당 입력 토큰

월 출력 토큰 = 요청 수 × 요청당 출력 토큰

월 비용 = 입력 토큰 ÷ 1,000,000 × 입력 단가

　　　 + 출력 토큰 ÷ 1,000,000 × 출력 단가

출력 단가가 입력의 4~5배인 모델이 많아요. 같은 토큰이라도 답변 쪽에 돈이 더 든다는 뜻이라, 답변 길이를 줄이는 것만으로 비용이 꽤 달라져요. 대화가 길어질 때 이전 대화가 매번 입력으로 다시 들어가는 점도 기억해 두세요.

요청 하나에 토큰이 얼마나 들어갈까

처음 계산할 때 감이 안 잡히면 아래 범위에서 시작해 보세요. 실제 값은 프롬프트 길이에 따라 크게 달라져요.

비용을 줄이는 6가지

  1. 모델을 용도별로 나누기. 분류·요약은 싼 모델, 판단이 어려운 일만 비싼 모델로 보내요.
  2. 프롬프트 캐싱 쓰기. 같은 지시문·자료를 반복해 보낸다면 캐시로 읽는 입력이 보통 입력 단가의 5~10%예요.
  3. 배치 API 쓰기. 급하지 않은 작업은 절반 가격이에요.
  4. 답변 길이 제한하기. max tokens를 정해 두면 출력 비용이 새지 않아요.
  5. 긴 대화는 요약해서 다시 넣기. 대화가 길어질수록 입력 토큰이 계속 늘어나요.
  6. 사용량 알림 걸기. 결제 한도와 알림을 먼저 설정해 두면 사고를 막을 수 있어요.

자주 묻는 질문

AI API 비용은 어떻게 계산하나요?

요청 수에 요청당 입력·출력 토큰을 곱해 월 토큰을 구하고, 100만 토큰당 단가를 곱해 더하면 돼요. 출력 단가가 입력보다 4~5배 높은 모델이 많아서 답변 길이가 비용을 크게 좌우해요.

입력 토큰과 출력 토큰은 무엇이 다른가요?

입력 토큰은 모델에 보내는 지시문·대화 기록·자료이고, 출력 토큰은 모델이 만들어 내는 답변이에요. 보통 출력이 더 비싸고, 대화가 길어지면 이전 대화가 매번 입력으로 다시 들어가 비용이 늘어나요.

프롬프트 캐싱을 쓰면 얼마나 아껴지나요?

같은 지시문이나 자료를 반복해서 보낼 때 캐시에 저장해 두고 다시 읽는 방식이에요. 캐시로 읽은 입력은 보통 입력 단가의 5~10% 수준이라, 긴 시스템 프롬프트를 쓰는 서비스에서 절감 효과가 커요.

배치 API는 얼마나 싼가요?

OpenAI·Anthropic·Google 모두 배치 처리를 쓰면 보통 절반 가격이에요. 대신 결과가 바로 오지 않고 보통 24시간 안에 처리되므로, 급하지 않은 대량 요약·분류 작업에 맞아요.

HeyGen이나 Synthesia는 왜 분당 요금이 없나요?

두 서비스는 사용한 분량을 크레딧으로 바꿔 차감하는 월 구독제예요. 예를 들어 Synthesia는 1분 영상에 보통 1,000~2,000 크레딧이 들고, 플랜마다 주는 크레딧이 달라서 필요한 영상 분량으로 플랜을 골라야 해요.

계산한 원화 금액이 실제 청구서와 같나요?

아니요. 계산기는 입력한 환율로만 바꿔 보여 줘요. 실제 결제에서는 카드 환율과 해외 결제 수수료, 부가세(VAT)가 붙어 조금 더 나올 수 있어요.

어떤 모델이 가장 싼가요?

용도에 따라 달라요. 짧은 분류·요약은 GPT-6 Luna나 Gemini 3.5 Flash-Lite, 긴 문서는 Gemini 3.8 Flash나 Claude Haiku 5.5가 저렴한 편이에요. 위 계산기에 같은 사용량을 넣고 모델만 바꿔 보면 바로 비교돼요.

How the token maths works

AI APIs bill by tokens, not characters. Price lists show dollars per million tokens (1M), so divide your usage by a million and multiply by the rate.

Monthly input tokens = requests × input tokens per request

Monthly output tokens = requests × output tokens per request

Monthly cost = input ÷ 1,000,000 × input rate + output ÷ 1,000,000 × output rate

Output usually costs 4–5× more than input, so answer length moves the bill a lot. Long conversations also resend earlier turns as input on every call.

Rough token counts per request

One short question100–300200–500
One support ticket (policy + thread)1,000–2,000200–400
Summarise a 2–3 page document3,000–6,000300–800
Fix one code file5,000–20,000500–2,000
Analyse a 20 page report25,000–50,0001,000–3,000

Korean text usually costs 1.3–2× the tokens of the same English text, and newer tokenizers can add around 30% more tokens for the same text. For exact numbers, use each provider's tokenizer or the usage field in the API response.

Worked examples

1. Support chatbot — 30,000 requests, 1,000 in / 300 out

That is 30M input and 9M output tokens. GPT-6.2 Sol comes to $150 a month, Gemini 3.8 Flash to $56.25, and GPT-6 Luna to $7.50. Routing simple questions to a cheaper model is the biggest saving most teams can make.

2. Batch summaries — 5,000 requests, 8,000 in / 800 out

40M input and 4M output. Claude Haiku 5.5 costs $6, or $3 with the 50% batch discount. Anything that can wait belongs in batch.

3. Video — 60 minutes at 720p

3,600 seconds × $0.07 = $252. At 1080p the same footage is $374.40. Avatar tools such as HeyGen and Synthesia use credits instead, so price those in the subscription panel.

4. Voice — 200,000 characters

That needs 200,000 ElevenLabs credits: Creator (121,000) is not enough, Pro (600,000, $99) is.

Six ways to cut the bill

  1. Split by task. Cheap models for classification and summaries, expensive ones only where judgement matters.
  2. Use prompt caching. Repeated instructions and documents are read back at roughly 5–10% of the input rate.
  3. Use batch APIs. Half price when you can wait.
  4. Cap the output. A max-token limit stops output spend from drifting.
  5. Summarise long threads. Every extra turn keeps being billed as input.
  6. Set spend alerts. A billing limit before launch beats a surprise invoice.

FAQ

How is AI API cost calculated?

Multiply requests by input and output tokens to get monthly tokens, then apply the per-million rates and add them. Output rates are usually 4–5× input, so answer length matters most.

Input vs output tokens?

Input is what you send — instructions, history, documents. Output is what the model writes. Output is pricier, and long chats re-send history as input every turn.

How much does prompt caching save?

Cached input is typically read at 5–10% of the normal input rate, which is a large saving for long system prompts.

How cheap is batch?

OpenAI, Anthropic and Google all charge about half for batch work, usually returned within 24 hours.

Why no per-minute price for HeyGen or Synthesia?

They sell monthly credit plans. Synthesia typically uses 1,000–2,000 credits per minute of video, so pick the plan by the minutes you need.

Is the KRW figure my actual bill?

No. It is a conversion at the rate you enter. Card FX spreads, overseas fees and VAT can make the real charge higher.
